# Schemas

`agent-plugins-1.0.0.json` is the official Agent Plugins 1.0 schema retrieved from <https://agent-plugins.org/schemas/1.0.0/plugin.schema.json> on 25 October 2026. It is vendored for deterministic validation and does not execute remote content.

Cursor manifest validation follows the official field reference at <https://cursor.com/docs/reference/plugins>. Host behavior still requires real-host testing.
