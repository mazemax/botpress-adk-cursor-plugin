# Privacy and data handling

This community distribution adds **no analytics, tracking pixel, telemetry, account collection, or remote maintainer service**. The repository contains Markdown skills and maintainer tooling; validation does not send project content to `mazemax`.

## Data processed by other products

The host (Cursor), the Botpress ADK CLI, Botpress Cloud, model providers, package registries, and GitHub have their own data practices. Skills can instruct the host to inspect project files, run ADK commands, access linked workspaces, or display logs and traces. Those operations are subject to the relevant product and account configuration; they are not anonymous merely because this plugin adds no telemetry.

Read `docs/side-effects.md` before invoking a workflow. Use a disposable ADK project and a non-production test workspace for evaluation. Never place real tokens, customer data, private source, or sensitive transcripts in public issues, fixtures, screenshots, or result files.

## Maintainer support data

Information deliberately sent through GitHub issues or the security contact may be processed for triage, security response, and maintenance. Do not submit information you are not permitted to share. Request removal through the security contact when a report contains sensitive material that should not be retained.

This page describes the distribution's design and support process; it is not a privacy policy for Botpress, GitHub, OpenAI, Cursor, or model providers.
