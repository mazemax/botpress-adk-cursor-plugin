# Test results

This directory stores deterministic baselines and dated, sanitized evidence summaries. `context-baseline.json` is generated by `npm run measure:context -- --write` and reviewed like any other upstream-facing change.

Host/model results must identify package version, upstream SHA, host/version, OS, model, date, repetition count, and limitations. Never store secrets, private project content, full sensitive transcripts, or reviewer credentials. An absent result is untested, not passed.
