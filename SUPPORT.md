# Support

Support is provided by `mazemax` for this community distribution, not by Botpress.

## Distribution support

Use [GitHub Issues](https://github.com/mazemax/botpress-adk-cursor-plugin/issues) for:

- Installation, discovery, update, rollback, or uninstall problems.
- Unexpected or missing skill activation, with the prompt and environment metadata.
- Incorrect host packaging, broken references, or release/provenance defects.
- Documentation gaps and reproducible compatibility evidence.

Use the issue template, search existing issues first, and redact tokens, personal data, private code, and workspace identifiers. The ordinary-issue acknowledgment target is **three business days**; this is not a guaranteed resolution time. Security reports follow `SECURITY.md` instead.

## Upstream ADK support

For incorrect ADK instructions or behavior in an unmodified upstream file, reproduce against [botpress/skills](https://github.com/botpress/skills) and use the `upstream-content` issue template to coordinate routing. Botpress does not support or endorse this distribution merely because its official skills are included.

## Maintainer scope

Support covers the package and its documented workflows. It does not include guaranteed debugging of private bots, production deployment, or custom ADK feature development.
